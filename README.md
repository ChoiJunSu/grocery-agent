# 🛒 스마트 장보기 에이전트 (MVP)

이마트 쓱배송 · 홈플러스 · 쿠팡 로켓프레시의 **가격 + 배송비 + 보유 쿠폰 + 배송 슬롯**을 종합해,
총 결제 금액이 가장 저렴한 **마트별 장바구니 분할 조합**을 찾아주는 개인화 장보기 에이전트.

봇 탐지 우회와 계정 보안을 위해 서버가 직접 크롤링하지 않고, **사용자 브라우저의 로그인 세션을 활용하는
크롬 익스텐션**이 데이터 수집과 장바구니 담기를 수행하는 하이브리드 구조다. **비밀번호는 절대 수집하지 않는다.**

```
┌─────────────┐   가격/쿠폰/슬롯 ingest   ┌──────────────┐   최적화 요청   ┌─────────────┐
│ Chrome 익스텐션 │ ───────────────────▶ │  API 서버      │ ◀────────────  │   웹 UI      │
│ (마트 로그인 세션) │ ◀─────────────────── │  (Fastify)    │ ─────────────▶ │ (Vite+React) │
└─────────────┘   장바구니 담기 작업 폴링   └──────────────┘   분할 계획 응답  └─────────────┘
        │                                      │
        ▼ DOM 스크립팅                          ▼ @grocery/core
   마트 장바구니에 자동 담기              쿠폰/배송비 기반 최적화 엔진
```

## 디렉토리

| 경로 | 역할 |
|---|---|
| `packages/core` | 최적화 엔진 + 타입 + mock 데이터. 순수 TS, 단위 테스트 완비 |
| `server` | Fastify API 서버 (port 3001). in-memory 저장소 |
| `extension` | Chrome Extension MV3. 빌드 불필요, 그대로 로드 |
| `web` | 웹 UI (Vite + React, port 5173) |
| `docs/ARCHITECTURE.md` | 설계 상세 |

## 로컬에서 전체 사이클 돌리기

### 1. 설치 & 테스트

```bash
npm install
npm test        # 최적화 엔진 단위 테스트 11개
```

### 2. API 서버 실행

```bash
npm run dev:server   # http://localhost:3001
```

### 3. 웹 UI 실행

```bash
npm run dev:web      # http://localhost:5173
```

브라우저에서 http://localhost:5173 접속 → 장보기 목록 선택 → **최적 조합 찾기**.
익스텐션이 없어도 서버 내장 mock 데이터로 즉시 동작한다.

### 4. 크롬 익스텐션 로드

1. 크롬에서 `chrome://extensions` 접속 → 우측 상단 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → `extension/` 폴더 선택
3. 마트 사이트(emart.ssg.com 등) 탭을 열어둔 뒤, 익스텐션 팝업에서 **가격 · 쿠폰 지금 동기화**
   → 서버의 해당 마트 데이터가 mock → live로 전환된다 (웹 UI 상단 배지로 확인)
4. 웹 UI에서 **장바구니에 자동 담기** 실행 → 익스텐션 background가 15초 주기로 작업을 가져가
   각 마트 탭에서 DOM 스크립팅으로 담기를 수행하고 결과를 보고한다

> 실제 마트 DOM 셀렉터는 아직 mock이다. 셀렉터가 매칭되지 않으면 각 어댑터가 mock 데이터로
> 폴백하므로 전체 사이클은 항상 끝까지 돌아간다. 실사이트 연동 지점은 코드에서
> `TODO(실사이트 연동)` 주석으로 검색하면 된다.

## 최적화 엔진 요약

- 목적함수: `Σ (마트별 소계 + 배송비 − 최적 쿠폰 할인)` 최소화
- 품목 수가 적으면(조합 ≤ 30만) **전수 탐색으로 전역 최적해**, 크면 최저가 초기해 + 지역 개선 greedy
- 무료배송 기준(마트별 상이), 쿠폰 minOrder/최대 할인 한도, 품절 상품 분리, 단일 마트 대비 절약액 계산

## API

| Method | Path | 설명 |
|---|---|---|
| GET | `/api/health` | 헬스체크 |
| GET | `/api/catalog` | 상품/마트 카탈로그 |
| POST | `/api/ingest` | 익스텐션이 수집한 마트 데이터 저장 |
| GET | `/api/ingest/status` | 마트별 mock/live 현황 |
| POST | `/api/optimize` | 장보기 목록 → 최적 분할 계획 |
| GET | `/api/plan/:id` | 계획 + 실행 상태 조회 |
| POST | `/api/execute` | 장바구니 담기 작업 큐 등록 |
| POST | `/api/actions/claim` | (익스텐션) 대기 작업 가져가기 |
| POST | `/api/actions/result` | (익스텐션) 담기 결과 보고 |
