# 서울 공공 테니스장 현황

코트마다 예약 페이지를 하나씩 열어보지 않고, **코트 × 날짜**를 한 화면에서 보는 로컬 웹페이지.
예약은 하지 않는다 — 현황만 보여주고 예약은 원래 사이트로 넘긴다.

```
npm install
npx playwright install chromium     # 슬롯 수집용 브라우저
cp .env.example .env                # SEOUL_API_KEY 채우기
npm run collect                     # 데이터 수집 → data/snapshot.json
npm start                           # http://localhost:3100
```

`SEOUL_API_KEY`는 [서울 열린데이터광장](https://data.seoul.go.kr/together/mypage/actKeyMain.do)에서 무료 발급.

---

## 무엇이 검증됐고 무엇이 안 됐나

이 프로젝트를 만든 환경에서 `yeyak.seoul.go.kr` / `openapi.seoul.go.kr:8088` / `ksponco.or.kr`
**모두 네트워크가 차단되어 있었다.** 그래서 실데이터로 확인한 것과 못 한 것이 나뉜다.

| 부분 | 상태 |
| --- | --- |
| 웹 UI (그리드·필터·상세 패널·곧 오픈) | ✅ 검증됨 — 픽스처로 렌더링·필터·클릭 동작 확인 |
| 서버, 스냅샷 API | ✅ 검증됨 |
| 오픈API 호출 코드 (`sources/yeyakApi.js`) | ⚠️ **미검증** — 공식 문서의 필드명 기준으로 작성 |
| yeyak 달력 스크래핑 (`sources/yeyakSlots.js`) | ⚠️ **미검증** — 실 DOM 확인 못 함 |
| 올림픽테니스장 (`sources/ksponco.js`) | ⚠️ **미검증** — 실 DOM 확인 못 함 |

첫 실행에서 슬롯이 0건이면 정상적인 실패다. 아래 진단기를 먼저 돌릴 것.

```
npm run diagnose -- "https://yeyak.seoul.go.kr/web/reservation/selectReservView.do?rsv_svc_id=S251203104822013240"
npm run diagnose -- "https://www.ksponco.or.kr/online/tennis/index.do" --html
```

진단기는 셀렉터 후보별 매칭 수, 휴리스틱이 인식한 년월·날짜칸·시간대칸, 그리고
아무것도 못 뽑았을 때 본문 앞부분과 iframe 목록까지 출력한다.
맞는 셀렉터를 찾으면 `src/config.js`의 `SELECTORS` 해당 배열 **맨 앞**에 추가하면 된다.

## 데이터 출처와 한계

**1. 코트 목록·접수상태 — 서울 열린데이터광장 오픈API** (`ListPublicReservationSport`, OA-2266)

공식 API라 안정적이다. 하지만 이 API가 주는 건 **코트 단위 메타데이터**까지다:
이름, 장소, 자치구, 유료/무료, 접수상태(접수중/예약마감), 접수기간, 이용기간, 좌표.

**"7월 30일 19시가 비었나"는 이 API에 없다.** 그래서 2단계가 필요하다.

**2. 날짜별 빈자리 — 상세 페이지 스크래핑**

공식 인터페이스가 아니다. 서울시가 예약 페이지를 개편하면 깨진다.
깨져도 조용히 틀린 값을 보여주지 않고 `errors`에 남겨 화면 하단에 노출한다.

스크래핑은 셀렉터 대신 **텍스트 패턴 휴리스틱**을 1차로 쓴다. 두 시스템 모두 마크업은
달라도 화면에 날짜 숫자·시간대 문자열·상태 한글('예약가능'/'마감')은 반드시 렌더링하기
때문이다. 셀렉터는 휴리스틱이 헛짚을 때 범위를 좁히는 힌트로만 둔다.

**범위 밖**: 강서구 등 자체 예약시스템을 쓰는 자치구는 포함하지 않는다.
시스템마다 구조가 달라 각각 어댑터를 붙여야 한다.

## 화면

- **그리드** — 행이 코트, 열이 오늘부터 30일. 칸의 숫자는 그 날 예약 가능한 시간대 수.
  날짜 단위 정보만 있는 코트는 `○`로 표시한다.
- **필터** — 코트·장소 검색, 자치구, 평일/주말, 유료/무료, 빈자리 있는 코트만.
- **칸 클릭** — 그 날 시간대별 가능/마감 목록 + 예약 페이지 링크.
- **곧 접수 오픈** — 접수 시작이 아직 안 온 코트를 시작 시각순으로. yeyak 테니스는
  보통 매월 10일·25일 10시에 열린다.
- **수집 실패** — 못 읽은 코트를 하단에 접어서 노출. 그리드에서 빈 줄로 보이는 이유가 여기 있다.

## 명령어

| 명령 | 설명 |
| --- | --- |
| `npm run collect` | 전체 수집 (오픈API + 브라우저 스크래핑) |
| `npm run collect -- --no-slots` | 코트 목록·접수상태만. 브라우저 불필요, 몇 초면 끝난다 |
| `npm run collect -- --only=yeyak` | yeyak만 (올림픽테니스장 제외) |
| `npm run diagnose -- <url> [--html]` | 셀렉터/휴리스틱 진단 |
| `npm start` | 로컬 서버 |

`.env`로 조절: `TENNIS_DAYS`(기본 30), `TENNIS_CONCURRENCY`(기본 3), `TENNIS_PORT`(기본 3100),
`TENNIS_CHROME_PATH`(playwright chromium 대신 쓸 크롬 경로).

## 수집 예의

공공 사이트를 상대로 하므로 동시 3개, 페이지당 0.7초 간격을 기본값으로 둔다.
`TENNIS_CONCURRENCY`를 올릴 수는 있지만 권하지 않는다. 자동 예약(매크로) 기능은 없고,
넣을 계획도 없다.
